# 🚀 Inicio Rápido - Gestión Personal V2

## ⚡ Pasos para ejecutar el proyecto

### Levantar todos los contenedores
```bash
docker compose up --build
```

⏳ Espera a que se descarguen las imágenes y se construyan los contenedores (primera vez puede tardar 3-5 minutos)

### 3️⃣ Acceder a las aplicaciones

✅ Una vez que veas el mensaje "Application startup complete" en la terminal:

- **Frontend (Aplicación Web)**: http://localhost:5173
- **Backend (Documentación API)**: http://localhost:8000/docs
